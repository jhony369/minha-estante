Adicionar e-books

Suba arquivos para a Biblioteca e escolha em qual gênero cada um aparece. Você pode criar gêneros novos.

Importante: tudo o que você subir aqui fica público. Qualquer pessoa com o link da estante consegue abrir. Suba só materiais que podem ser divulgados, como regras, manuais e leis oficiais. Nada de conteúdo confidencial.

1. Conectar

Para publicar, esta página precisa de uma chave do GitHub. A chave fica guardada só neste aparelho e não vai para o site.

Como criar a chave (só uma vez)
  1. Abra github.com/settings/personal-access-tokens/new com a sua conta do GitHub.
  2. Token name: Minha Estante. Expiration: escolha a validade que preferir.
  3. Repository access: Only select repositories → escolha minha-estante.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Toque em Generate token, copie a chave e cole abaixo.
